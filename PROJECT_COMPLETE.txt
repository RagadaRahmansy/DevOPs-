## 🚀 Quick Start

### Step 1: Setup Database (5 min)
```bash
psql -U postgres
CREATE DATABASE cafe_analytics;
\c cafe_analytics
\i 'C:/path/to/database/schema.sql'
\i 'C:/path/to/database/sample_data.sql'
\q
```

### Step 2: Setup Backend (5 min)
```bash
cd backend
cp .env.example .env
# Edit .env with your PostgreSQL password
npm install
npm run migrate
npm run dev
```

### Step 3: Setup Frontend (5 min)
```bash
cd frontend
npm install
npm start
```

### Result
✅ Dashboard running at http://localhost:3000
✅ API running at http://localhost:5000/api
